# Baumenü-Icons (RTS-Bau-Menü)

Hier liegen die Icons für das RTS-Baumenü. Dateiname = die **id** des Baus bzw.
der Kategorie (siehe src/data/rts.ts, RTS_BAUTEN). PNG, transparent, ~256×256.

Sobald eine Datei hier liegt, zeigt das Menü das Icon statt Text; der Name
erscheint nur noch als Tooltip. Fehlt die Datei, bleibt der bisherige Text.

## Kategorie-Reiter
- `wehr.png`        → Befestigung  (Palisade + Turm)
- `lager.png`       → Lager        (Zelt)
- `versorgung.png`  → Versorgung   (Fass + Brot)
- `zeichen.png`     → Feldzeichen  (Banner)

## Bauten (Auswahl, id = Dateiname)
palisade, wachturm, tor, lagerfeuer, zelt, lazarett, nachschub, feldschmiede,
kochstelle, brunnen, botenposten, pferdekoppel, feldaltar, wartfeuer, standarte,
ritter, gewappneter, spiesser, armbruster, bogenschuetze, feldscher,
linie, schildwall, keil, plaenkler
