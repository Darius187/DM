    Stimme fehlt? Englische oder (Natural)-Stimme installieren

    Schnellste Alternative ohne Installation – Online-Stimme (edge-tts): nutzt die natürlich klingenden Neural-Stimmen aus Microsoft Edge über das Internet. Nichts wird installiert, kein Registry-Eingriff. Hier nur zum Ausprobieren – Verbindung und Klang testen:

    Hinweis: Braucht eine Internetverbindung; der vorgelesene Text geht dabei an Microsofts Server.

    Die App listet sonst nur Stimmen, die Windows der Web-Speech-Schnittstelle anbietet. Englische Stimmen sind nach einer frischen Windows-Installation oft nicht dabei. So holst du sie nach:

    1. Windows-Einstellungen → Zeit und Sprache → Sprache und Region.
    2. Unter Bevorzugte Sprachen bei der Sprache (z.B. Englisch (Vereinigtes Königreich)) auf die drei Punkte → Sprachoptionen.
    3. Bei Sprache auf Stimmen hinzufügen und die gewünschte Stimme installieren, z.B. Microsoft Ryan, Microsoft Sonia.
    4. App neu starten — die Stimme erscheint im Dropdown.

    Wichtig zu den (Natural)-Stimmen aus Windows 11: Microsoft hat zwei Sorten:

    • Klassisch (SAPI 5) — z.B. „Microsoft Hedda Desktop", „Microsoft Stefan". Werden zuverlässig in dieser App angezeigt.
    • Neu „(Natural)" / „Modern" — z.B. „Microsoft Conrad (Natural)", „Microsoft Katja (Natural)". Sind in Windows-Einstellungen → Barrierefreiheit → Sprachausgabe über Sprachausgabestimmen hinzufügen installierbar (sehr natürlich klingend). Aber: diese Modern-Stimmen reicht Windows in der Regel nur an die Sprachausgabe und Erzähler-Apps weiter, nicht an die Web-Speech-Schnittstelle, die diese App nutzt.

    Trick für die (Natural)-Stimmen: Die Modern-Stimmen liegen in einem Registry-Pfad (Speech_OneCore), aus dem Chromium nicht liest. Wenn du sie in den klassischen Speech-Pfad kopierst, sieht diese App sie.

    1. Vorher Wiederherstellungspunkt setzen. Start → „Wiederherstellungspunkt erstellen" → Erstellen.
    2. Start → PowerShell oder Terminal mit der rechten Maustaste → Als Administrator ausführen.
    3. Snippet mit dem Knopf unten kopieren, in PowerShell einfügen und mit Enter ausführen.
    4. Schachtrainer schließen und wieder öffnen.
    $src = 'HKLM:\SOFTWARE\Microsoft\Speech_OneCore\Voices\Tokens'
$dst = 'HKLM:\SOFTWARE\Microsoft\Speech\Voices\Tokens'
Get-ChildItem $src | ForEach-Object {
  Copy-Item -Path $_.PSPath -Destination "$dst\$($_.PSChildName)" -Recurse -Force
  Write-Host "kopiert:" $_.PSChildName
}

    Trainer (Ollama)

    Ollama über das Netzwerk verbinden (Tablet/Surface → Hauptrechner)
    1. Auf dem Hauptrechner (wo Ollama läuft) die IP herausfinden: Eingabeaufforderung öffnen, ipconfig eingeben, bei "IPv4-Adresse" steht z.B. 192.168.1.50.
    2. Ollama dort fürs Netzwerk freigeben: Umgebungsvariable OLLAMA_HOST=0.0.0.0 setzen und Ollama neu starten. Ohne das lauscht Ollama nur auf dem Rechner selbst.
    3. In der Windows-Firewall des Hauptrechners den Port 11434 zulassen.
    4. Hier auf dem Tablet/Surface ins Adressfeld die IP mit Port eintragen, z.B. 192.168.1.50:11434 - nicht "localhost".
    5. Klappt es, erscheinen die Modelle des Hauptrechners als Vorschläge. Dann mit "Speichern" als Verbindung sichern.

    "localhost" heißt "dieser Rechner hier" - richtig, wenn Ollama auf demselben Gerät läuft, aber falsch fürs Tablet, das auf den Hauptrechner zugreifen soll.
